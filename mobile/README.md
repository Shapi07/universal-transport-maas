# 📱 OmniPass MaaS — Мультимодальный мобильный прототип (React Native / Expo)

> Интерактивное мобильное приложение для университетских защит и презентаций концепции **Mobility as a Service (MaaS)** и алгоритма **Dynamic Disruption Recovery (динамическое восстановление стыковок)**.

---

## 🌟 Новые возможности (v2.4)

1. **🇷🇺 / 🇬🇧 Полная двуязычность (RU / EN)**:
   - В правом верхнем углу главного экрана расположен переключатель языка.
   - По умолчанию интерфейс полностью на русском языке (станции, билеты, расписание, уведомления, роли).

2. **🔀 Интерактивный выбор мультимодальных маршрутов**:
   - «⚡ Рекомендуемый (самый быстрый)»: Автобус + Скоростной поезд + Такси (1ч 50м, 2 890 ₽).
   - «💰 Экономичный»: Автобус + Метро (2ч 15м, 1 020 ₽).
   - «🚀 Экспресс»: Аэроэкспресс + Премиум Такси (1ч 10м, 4 080 ₽).
   - Карточки интерактивны — можно нажимать и выбирать подходящий вариант.

3. **💳 Модальное окно покупки и оплаты**:
   - Выбор платежного шлюза: **СБП**, **Банковская карта (Мир)**, **OmniPass Кошелек**.
   - Анимация успешного оформления единого сквозного билета.

4. **🎫 Цифровой QR-билет с полноэкранным режимом**:
   - Можно нажать на QR-код или кнопку «Развернуть во весь экран», чтобы показать контролёрам турникета или водителю.

5. **🚨 Расширенный симулятор диспетчера (Operator Disruption Hub)**:
   - Выбор времени задержки: **+15 мин**, **+20 мин**, **+30 мин**, **+45 мин**.
   - Выбор причины инцидента: сбой светофоров, сильный снегопад, ремонтные работы.
   - **Симуляция Push-уведомления водителю такси**: уведомление водителю о переносе подачи без штрафа за простой.
   - Кнопка быстрого перехода к проверке результата у пассажира.

## 🚀 Как запустить за 30 секунд (в браузере через Expo Snack)

Самый быстрый и безотказный способ для демонстрации комиссии:

1. Откройте в браузере: **[https://snack.expo.dev](https://snack.expo.dev)**.
2. В файле `App.js` слева вставьте код из [`App.js`](./App.js).
3. Справа нажмите **Web** (или **Android / iOS**) — интерактивный телефон сразу запустится!

---

## 💻 Локальный запуск на компьютере

```powershell
cd C:\universal_transport_maas\mobile
$env:Path = "C:\Program Files\nodejs;" + $env:Path
npx expo start
```
- Нажмите клавишу **`w`** в терминале для запуска веб-версии.
- Либо отсканируйте QR-код в приложении **Expo Go** на телефоне.

## 🎬 Сценарий показа на защите проекта (3 шага)

1. **Шаг 1 (Пассажир):**
   - Нажмите **«Войти как Пассажир»**.
   - Откройте вкладку **«Мой Единый билет»**.
   - Покажите комиссии: сегмент №3 (такси SwiftCab) запланирован на **09:25 – 09:50**. Билет в статусе **«ПО ГРАФИКУ»**.

2. **Шаг 2 (Симуляция сбоя):**
   - Нажмите в правом верхнем углу кнопку **«Режим диспетчера ➔»**.
   - Выберите опоздание (например, **+20 мин**).
   - Нажмите красную кнопку: **«🚨 СИМУЛИРОВАТЬ ЗАДЕРЖКУ (+20 МИН)»**.
   - Покажите push-уведомление таксисту: заказ перенесен, плата за ожидание отменена.

3. **Шаг 3 (Демонстрация алгоритма MaaS):**
   - Нажмите **«Режим пассажира ➔»**.
   - Обратите внимание комиссии:
     - ⚠️ Появился желтый баннер: *«Внимание: Задержка рейса. Подача такси автоматически перенесена на 09:45. Штраф: 0 ₽.»*
     - Время подачи такси в билете само изменилось на **09:45 – 10:10**!
